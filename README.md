## **Instagram**

#### **Sobre**



Instagram é uma aplicação móvel de compartilhamento de fotos e vídeos que permite aos usuários capturar, editar e compartilhar conteúdo visual com seus seguidores. A plataforma, desenvolvida para iOS e Android, permite que os usuários postem imagens, vídeos, histórias e reels, além de interagir com conteúdo de outros usuários através de curtidas e comentários.



#### **Público Alvo**

* Usuários de smartphones (iOS e Android) com idade de 13 anos ou mais
* Criadores de conteúdo (influenciadores, fotógrafos, artistas)
* Pequenas empresas e marcas
* Usuários que buscam interação social e compartilhamento visual
* Anunciantes interessados em publicidade digital



#### **Funcionalidades Principais**

* **Compartilhamento de Fotos e Vídeos:** Upload e publicação de imagens e vídeos editados
* **Filtros e Ferramentas de Edição:** Aplicação de filtros artísticos e ajustes de imagem
* **Histórias (Stories):** Publicação de conteúdo efêmero que desaparece após 24 horas
* **Reels:** Criação e compartilhamento de vídeos curtos (até 90 segundos)
* **Feed de Descoberta:** Exploração de conteúdo de contas não seguidas
* **Mensagens Diretas (DM):** Comunicação privada entre usuários
* **Notificações:** Alertas sobre curtidas, comentários e seguimentos
* **Busca e Hashtags:** Descoberta de conteúdo por palavras-chave
* **Live:** Transmissões ao vivo em tempo real
* **Compras:** Integração com lojas de e-commerce



#### **Tecnologias Utilizadas**

##### **Backend**

* **Python** - Linguagem de programação principal
* **Django** - Framework web de alto nível
* **PostgreSQL** - Banco de dados relacional
* **Cassandra** - Banco de dados NoSQL para escalabilidade
* **Memcached** - Sistema de cache em memória
* **RabbitMQ** - Message broker para filas de mensagens
* **Celery** - Task queue distribuída para processamento assíncono
* **Apache** Solr - Motor de busca e indexação
* **Nginx** - Web server e proxy reverso
* **AWS** - Infraestrutura em nuvem (EC2, S3, CloudFront, DynamoDB)



##### **Mobile (Frontend)**

* **React Native** - Framework para desenvolvimento multiplataforma
* **Swift** - Linguagem nativa para iOS
* **Java/Kotlin** - Linguagens nativas para Android



##### **Infraestrutura**

* **Amazon Web Services (AWS)** - Hospedagem em nuvem
* **CDN (Content Delivery Network)** - Distribuição de conteúdo
* **Docker** - Containerização de aplicações
* **Kubernetes** - Orquestração de containers



#### **Requisitos Técnicos para Utilização**

##### **Para Usuários (Aplicativo Móvel)**

* **iOS:** iPhone/iPad com iOS 14.0 ou superior
* **Android:** Dispositivos com Android 6.0 (API 23) ou superior
* **Conexão de Internet:** WiFi ou dados móveis 3G/4G/5G
* **Armazenamento:** Mínimo 200 MB de espaço livre
* **Câmera:** Câmera frontal e traseira funcionando corretamente
* **Permissões:** Acesso à câmera, galeria de fotos, microfone e localização (opcional)
